    Back up and restore

    Save your rules and settings to a file, or load them from one, for example on another computer.

    Importing adds the rules from the file and replaces your rules for the same websites. Your other rules are kept. Settings are restored from the file too.

    Good to know

    • Firefox doesn’t let extensions choose the folder before a file is saved. So when a download from a website with a rule has finished, DownHere downloads the file again into the rule’s folder, checks that both copies match and deletes the first one. For a moment you’ll see both in the downloads list.
    • Some downloads can’t be repeated, so they stay where Firefox saved them: files a page creates itself (their address starts with blob:), files you get by sending a form, links that only work once, downloads in container tabs, and files you choose a place for yourself.
    • Chrome only lets extensions save files inside your Downloads folder (the location set in Chrome’s Settings › Downloads). DownHere creates the folders you choose there automatically.
    • Firefox only lets extensions save files inside your Downloads folder (the one set in Firefox’s Settings › General › Files and Applications). DownHere creates the folders you choose there automatically.
    • Browse… opens your browser’s save dialog, because a folder dialog wouldn’t tell DownHere where the folder is. Open the folder you want, or create one, and click Save, keeping the suggested name. DownHere saves a small file there and a second one directly in your Downloads folder, works out which folder you chose, and deletes both files right away.
    • A rule for example.com also covers www.example.com. Switch on “Include subdomains” to cover addresses such as files.example.com too. When several rules fit the same address, the most specific one wins.
    • DownHere only chooses the folder; files keep the name Chrome gives them. Outside Windows, a few names that some versions of Chrome don’t allow inside folders (such as CON.txt) stay in the Downloads folder.
    • DownHere only chooses the folder; files keep the name Firefox gives them. Files with % in their name (which Firefox would change) and a few unusual names such as CON.txt stay in the Downloads folder.
    • If Chrome is set to ask where to save each file, the save dialog suggests the rule’s folder. After Browse…, Chrome then also asks about DownHere’s second small file, “DownHere - Downloads folder check.txt”: click Save without changing the folder.
    • Rules only apply in Incognito windows if you allow DownHere in Incognito (chrome://extensions › DownHere › Details).
    • Rules only apply in private windows if you allow DownHere to run in them (about:addons › DownHere › Run in Private Windows).
    • While DownHere is on and has a rule switched on, Chrome ignores the folder and file name that other extensions ask for when they download something. Pause DownHere to let them choose again.
    • If another extension also watches downloads while Chrome names them (download managers and organizers often do), Chrome lets only one of them decide while both are active: the one installed or updated most recently, even for downloads it doesn’t change.
    • Files that other extensions download are left where those extensions put them.
    • Your rules are stored only in this browser. DownHere doesn’t send any data anywhere.
    • Your rules are stored only in this browser. DownHere doesn’t send any data anywhere; it only downloads files a second time from the address they came from.
